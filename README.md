# HotkeyWin11

Переключатель звуковых устройств для Windows 11. Появляется списком по центру экрана и работает так же, как переключатель языка: удержали **Win**, нажали **J** нужное число раз, отпустили **Win** — выбор становится текущим.

Короткое нажатие сразу выбирает следующее устройство. Окно не забирает фокус у программы, в которой вы работаете.

## Сочетания

| Сочетания | Что переключает |
| --- | --- |
| `Win` + `J` | Устройства вывода: монитор, наушники, колонки, HDMI |
| `Win` + `Alt` + `J` | Устройства ввода: микрофоны и другие источники записи |

Над списком подписано **Вывод** или **Ввод**.

Выбранное устройство назначается сразу для трёх ролей Windows: обычный звук, мультимедиа и связь. Его подхватывают и система, и программы вроде Zoom или Discord.


## Готовый exe

Python не нужен. Файл лежит в папке [`release`](release):

[HotkeyWin11.exe](release/HotkeyWin11.exe)

Скачайте его и запустите. В трее появится значок переключателя.

Чтобы программа включалась вместе с Windows, один раз выполните в этой папке:

```powershell
.\HotkeyWin11.exe --startup
```

## Установка

Нужны Windows 10 или 11 и Python 3.11 или новее.

```powershell
git clone https://github.com/mahmudproduction/hotkeywin11.git
cd hotkeywin11
py -3 -m pip install -r requirements.txt
py -3 input_switcher.py --startup
```

`--startup` создаёт ярлык в автозагрузке и запускает переключатель. После перезагрузки он стартует сам, без окна консоли.

Посмотреть списки, ничего не меняя:

```powershell
py -3 input_switcher.py --check
```

## Выход

Правый щелчок по значку переключателя в трее и пункт **Выход**.

Из консоли:

```powershell
py -3 input_switcher.py --exit
```

Убрать ярлык из автозагрузки:

```powershell
py -3 input_switcher.py --remove-startup
```

## Если сочетание не сработало

Сначала закройте уже запущенный переключатель и откройте его снова. Если `Win` + `J` занят другой программой, закройте и её. Сочетание `Win` + `L` Windows не отдаёт: его использовать нельзя.
